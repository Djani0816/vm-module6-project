# Module 6 – Virtual Memory Project

This project is a Python simulation of a Virtual Memory Management system.

## What it does:
- Simulates physical memory (RAM)
- Simulates virtual memory
- Handles page faults
- Uses Least Recently Used (LRU) page replacement
- Tracks dirty pages (modified pages)
- Simulates disk reads and writes
- Displays memory statistics

## Files in this project:
- vm_module6.py → Main Python program
- output.png → Program output screenshot
- Module6_Report.docx → Written explanation/report

## Purpose:
This project demonstrates how operating systems manage memory when RAM is limited by using virtual memory techniques.
